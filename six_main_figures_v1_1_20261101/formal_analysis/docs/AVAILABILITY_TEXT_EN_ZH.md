Replace [NEW_VERSION_DOI] with the real v1.0.1 DOI after publication. Do not use

## English

Data availability. Processed inputs for the sequence-baseline, within-family
and group-separated selection analyses, together with frozen statistical
outputs, are available with the analysis code at
https://github.com/Rainandbow/amp-systematic-evaluation and archived in version
v1.0.1 ([NEW_VERSION_DOI]). Historical statistical inputs retain sequence SHA256
identities, source labels, dependence groups and saved model outputs; historical
raw sequence letters are not redistributed. Experimental source data are
available with the cited ApexGO and HydrAMP publications. Original data for the
separate APEX/AMPGen panel remain with their source publications. File-level
provenance, transformations, access routes and licensing scopes are documented
in the repository. This deposit supports the specified saved-output statistical
analyses and does not bundle third-party weights or all original source files.

Code availability. Analysis and figure-generation software is available at
https://github.com/Rainandbow/amp-systematic-evaluation and archived as version
v1.0.1 ([NEW_VERSION_DOI]). Software uses Apache 2.0; the specified processed
data use CC BY 4.0 with original-source attribution. The archive includes input
fingerprints, numerical checks, the frozen protocol and reconstruction commands.
Fresh model inference requires the original third-party model environments and
weights.
