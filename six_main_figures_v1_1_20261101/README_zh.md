# 六张主图统一复算

本包已在本地运行。最短流程为 `python run.py check`、`python run.py points`、`python run.py figures`。

- `points`：从冻结标签、分数、原生判定、长度、家族和依赖块重算点估计，并核对原表。
- `figures`：用归档点估计及原区间重绘六张当前主图，检查版面。不重新推理或重采样。
- `uncertainty`：图2、图3及图6的ApexGO部分另做1万次分组bootstrap核验，使用新的固定种子；不覆盖原区间。
- `baseline`：用原协议重跑图4的全部六种简单规则、两种任务、家族内指标及配对区间。
- `transfer`：重跑图5的六折、每折20次组划分与三类规则。

图1是成员计数，无需置信区间。图5中的点云是重复组划分敏感性，不是置信区间。图6a的84条分母与共支持76条不同；图4d只有90条信息家族成员，不能写成与 pooled AUROC 完全同一分母。

重绘再次运行时使用新输出位置，如 `python run.py figures --output rerun2`。文件名和目录名采用ASCII，避免超算解压中文乱码。历史序列用SHA256替代，足以复算已保存输出的统计量，但不能恢复序列、分组或模型推理。原始论文数据的访问入口和许可保留在 formal_analysis/docs 中。
