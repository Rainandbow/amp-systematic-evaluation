## Historical source relationships

The public statistical tables retain the evaluation's source labels, exact
sequence SHA256 identities, saved predictions/scores and frozen dependence
groups. Historical raw sequence letters are not included. Consult the original
sources for sequence retrieval and their applicable terms:

| Evaluation source | Original source or implementation access |
|---|---|
| AMPlify | https://github.com/BirolLab/AMPlify ; https://doi.org/10.1186/s12864-022-08310-4 |
| tsAMP-I | https://github.com/YangLab-BUPT/tsAMP ; https://doi.org/10.3389/fmicb.2026.1842380 |
| c_AMPs source-derived resplit | https://github.com/mayuefine/c_AMPs-prediction ; https://doi.org/10.1038/s41587-022-01226-0 |
| HMD-AMP | https://github.com/ml4bio/HMD-AMP |
| AmPEP raw source | https://doi.org/10.1038/s41598-018-19752-w |
| ampir raw mature90-derived set | https://github.com/Legana/ampir ; https://doi.org/10.1093/bioinformatics/btaa653 |

The named sets are the evaluation's frozen comparison datasets, not a claim that
each is an unchanged official test partition. Original sequence recovery,
new model inference and reclustering are distinct from statistical recomputation
using the saved outputs distributed here.
